# CRASHOVERRIDE — Product design handoff for Work

**Product:** browser-first desktop investigation console with mobile read-only views. **Outcome:** researchers can investigate source-grounded DeFi risk signals on Solana and Arbitrum, inspect uncertainty and produce a reviewable dossier; academy users can practice on unmistakably synthetic scenarios.

## Reference corpus and interaction priorities

The reference galleries depict black-screen CRT / VGA / ASCII hacker aesthetics, acid green terminal typography, amber caution, red alerts, movable panes, mission boards, node/flow graphics, reputation/crew mechanics and interactive commands. The updated design should preserve the cinematic identity without confusing a simulation with real returns or a terminal command with actual financial execution.

**Primary experience:** evidence-first GIBSON terminal and observatory, with chain selector, dataset type, event age, status, review owner and source chips. **Secondary:** APEX hypotheses and falsifiers, WOLF PACK agent-review queue, DIA public intelligence, HYENA risk lab, HACK THE PLANET Academy, Governance/Legal issue board, Economics simulator and Evidence Vault.

## Visual direction / constraints

- Dark neutral base, terminal phosphor green as a sparing functional accent, amber for uncertainty, red for genuine HOLD/critical problems, not decorative alarm inflation.
- Monospaced data views with readable proportional supporting copy; clear contrast and focus treatment, charts with labels independent of color.
- Progressive disclosure: new researchers have a guided inspect path; advanced researchers can use the command palette and shortcuts.
- The device is a research console: `SCAN`, `REPLAY`, `EXPLAIN`, `EXPORT`, `REVIEW`, `COMPARE`; the UI contains no live TRADE, ATTACK, EXTRACT, HIDE, or WALLET-SIGN action.
- Avoid flashing, simulated phishing/login claims, fake live mempools, vague 'access granted' that implies identity verification, fake profit tickers and fear-of-missing-out timers.
- Every synthetic amount prominently says `SIMULATED`; source assertions are `UNVERIFIED` unless accepted against evidence.

## Critical flows to visualize

1. **First entry:** open demo without wallet, choose Solana vs Arbitrum, see data mode `OFFLINE SYNTHETIC`.
2. **Event triage:** click event; inspect observations, confidence vs probability, alternatives and missingness.
3. **Replay:** run deterministic fixture, inspect resulting claim statuses and export dossier/hash.
4. **Agent handoff:** see G1/D1/E1/S1/D3 tasks, asynchronous statuses and explicit human approval boundary.
5. **Research education:** enter HACK THE PLANET academy, solve a synthetic misleading claim and see explanation.
6. **Governance review:** read legal and economic claims with red flags, open objections and pending sign-off.

**MVP acceptance:** event-to-evidence reachability, zero deceptive financial widgets, clean mobile read-only layout, keyboard access, labeled data age, all claim states distinguishable, genuinely functional export/replay controls in a later selected implementation.
